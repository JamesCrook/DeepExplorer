24px per parameter vs ~34px for the stacked label+slider. Drag maps absolutely (click position = value); full row width = full range. B1 fill is chroma at 18% alpha — louder but the value shape reads from peripheral vision; B2 fill is a neutral raise (#232c49) — the Blender approach, value shape readable only on direct look, zero chroma cost across twenty sliders. Variant C uses the standard cursor, per native range controls; A and B keep ew-resize as the drag affordance. Caution: fills can read as progress bars near a chat stream.

4 · server icon fading lab (canvas, per-pixel)

Linear desaturation, per your finding. Consequence for production: no canvas needed at all — this is exactly filter: saturate(0.33) brightness(0.66) with a CSS transition for the wake, GPU-cheap and one line per state.
